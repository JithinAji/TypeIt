@jithinaji/typeit

A lightweight JavaScript typing animation library with natural human-like variation.

GitHub Repository npm Package
demo.js
Automatically keeps cursor in view when text overflows parent element

Quick Usage

// Browser / CDN / ES Module
const element = document.getElementById("target");
const typist = new TypeIt({
  element: element,
  typingSpeed: 120,    // Base speed in milliseconds (default: 150)
  speedVariation: 40,  // Random variation in milliseconds (default: 50)
  autoScroll: true     // Automatically scroll parent to bottom (default: true)
});

typist
  .type("Hello, world!")
  .type(" Welcome to modern web development.");
